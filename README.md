
# Cybersecurity Learning Journey

## About

This repository documents my journey of learning cybersecurity through hands-on practice, research, labs, CTFs, and security write-ups. The goal is to build a strong foundation in ethical hacking, web application security, penetration testing, and bug bounty hunting while maintaining a structured knowledge base for future reference.

Rather than collecting certificates or completing courses passively, this repository focuses on understanding concepts, practicing them in labs, and documenting lessons learned through detailed notes and write-ups.
